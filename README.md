## 자동 만료

`.github/workflows/expire.yml` 이 3시간마다 실행되어, 아래 시각이 지나면
GitHub Pages 사이트를 삭제하고 제안서 파일을 제거합니다.
GitHub 서버에서 실행되므로 로컬 PC 전원과 무관합니다.

```
만료: 2026-08-01T14:00:00Z  (2026-08-01 23:00 KST)
```

### 즉시 내리려면

```bash
gh api --method DELETE repos/soulairise/yoga-collab-proposal/pages
```

또는 Actions 탭에서 "공개 배포 자동 만료" 워크플로를 수동 실행(Run workflow)하세요.
만료 시각을 바꾸려면 워크플로의 `EXPIRES_AT` 값을 수정하면 됩니다.
